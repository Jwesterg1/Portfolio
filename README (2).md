# Screenshots

This folder contains sanitized screenshots from the Microsoft Sentinel lab environment.

All screenshots have been redacted to remove:
- Tenant IDs and Subscription IDs
- Workspace names and resource group names
- Email addresses and UPNs
- Internal IP addresses and hostnames
- Organization name and any identifying information
